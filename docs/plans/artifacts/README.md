# Cowboy Migration Artifacts

This directory stores generated artifacts produced by each migration batch.

Expected examples:

- endpoint inventory and compatibility matrix
- route normalization spec
- security/error taxonomy notes
- parity notes per endpoint group
- contract harness/performance reports
- cutover/rollback runbooks
- deferred-track ADRs and multi-DC distribution specs

Each artifact should be referenced by at least one batch `Context Capsule` and the context chain row.
